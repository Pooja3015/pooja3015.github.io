# G Pooja — Professional Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `pooja_professional_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Check the resume in `assets/G_Pooja_Resume.pdf`.
- Verify all project descriptions and dates.
- Add repository/demo links for projects that currently show "Add repository or demo link when available".
- Add LinkedIn if you want it displayed.
- Check that the email address and other contact details are correct.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `pooja3015.github.io`.
2. Upload the contents of this folder (the files inside the folder, not the outer folder).
3. In repository Settings → Pages, select deployment from the `main` branch and root folder.
4. Wait for GitHub Pages to publish the site. The URL should be `https://pooja3015.github.io/`.

## Privacy and accuracy
The portfolio uses only the details in the supplied resume and public GitHub profile. Project descriptions are based on the resume/profile information. Verify the descriptions before publishing. Do not add secrets, passwords, API keys, or private datasets to a public repository.
